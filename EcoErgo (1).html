    RESEARCH METHODOLOGY

    How This Project Works

    🩺

    Physiotherapy (BPT)

    Select and review exercises, write posture guidance and safety instructions. All routines should be checked by a qualified physiotherapist.

    💻

    Technology (B.Tech)

    HTML, CSS and JavaScript website on free hosting. Progress is stored in the browser (localStorage); charts use Chart.js.

    📋

    Evaluation (joint)

    Staff survey, usability testing and pre/post feedback. The optional discomfort sliders can supply self-reported data for analysis.

    Green Score (0-100, last 7 days)

      Carbon estimate

      CO₂e = pages × factorpage + trips × distance × factormode

      Factors are illustrative and listed in data.js. Healthcare visits are never converted into carbon savings automatically.

      Limitations

      • Self-reported inputs; savings are estimates, not measurements.
      • Data stays in one browser. Sharing across users needs a backend.
      • Reminders only run while the page is open.
      • Demo data is simulated and is not real staff or institutional data.

      Health and Safety

      This student project provides general educational information and does not diagnose or treat medical conditions. Have a qualified physiotherapy professional review the exercise routines. Stop if an exercise causes pain, dizziness, numbness or worsening symptoms. Seek appropriate medical advice for persistent or severe symptoms.
